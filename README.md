Mines Fairness Lab

An educational web-based tool for understanding SHA-256 server seed hash verification.

Features

- SHA-256 server seed hash verification.
- Hash format validation.
- Verification result display.
- Interactive 5×5 grid demonstration.
- Reset functionality.

How to Use

1. Open the deployed website.
2. Enter the Server Seed Hash.
3. Enter the Revealed Server Seed.
4. Click VERIFY HASH.
5. Check whether the hashes match.

Technology

- HTML
- CSS
- JavaScript
- Web Crypto API (SHA-256)

Deployment

This project can be deployed using Vercel and connected to GitHub.

Disclaimer

This project is an educational fairness verification tool. It does not predict gambling outcomes, identify safe Mines cells, or guarantee results.
